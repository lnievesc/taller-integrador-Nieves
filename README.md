# Taller integrador individual — Luis Nieves

## Auditoría y corrección del sitio web

### Hallazgos de la auditoría

| Defecto encontrado | Por qué es un problema | Cómo se corrigió |
|---|---|---|
| Nombres de archivos con espacios y mayúsculas | No siguen una convención uniforme | Se renombraron usando minúsculas y guiones |
| Título de página poco descriptivo | No identifica correctamente la página | Se cambió por "Calculadora de Promedio" |
| Nombres de variables poco descriptivos | Dificultan la comprensión del código | Se utilizaron nombres relacionados con su función |
| IDs poco descriptivos | Dificultan identificar los elementos HTML | Se cambiaron por nombres más claros |
| Función `calc()` | El nombre no describe claramente su función | Se cambió por `calcularPromedio()` |
| Variable `data1` sin uso | No cumple ninguna función | Se eliminó |
| Código antiguo comentado | Es código innecesario | Se eliminó |
| Mensajes `console.log` | Eran mensajes de depuración innecesarios | Se eliminaron |
